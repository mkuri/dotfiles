# Product Naming

Each owner has its own naming theme. Apply it to new products only; do not
rename existing products (for example `finance`, `home-infra`) to fit a theme.

## `cloveclovedev` products: spices

Name `cloveclovedev` products after spices (`clove`, `cumin`, `peppercheck`,
`anisecode`). Reserve spice names for `cloveclovedev`; never use them for a
personal product, so the pool does not run out.

## `mkuri` personal products: retro games

- Base the name on the world of retro games (arcade, 8-bit and 16-bit consoles).
- Basketball terms and general game terms are also allowed.
- The name should be a pun on what the product does, not just a theme word.
- Use a short lowercase kebab-case English word or phrase that works as a
  repository name, and check that `mkuri/<name>` is free before proposing it.

When proposing names, offer a few candidates across the allowed sources with
the pun explained for each, and let the user choose.
